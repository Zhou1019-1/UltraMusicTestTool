## 一、软件简介

本软件用于验证音频文件的**真实质量**：识别把有损音频（MP3/AAC 等）转码伪装的"假无损"、
把 44.1kHz/16bit 升频假造的"假 Hi-Res"，同时提供完整的元数据查看与批量标签编辑功能。
所有分析均在**本机离线完成**，音频文件不会上传到任何服务器。

## 二、安装与启动

### 安装包方式
1. 双击 `无损鉴别-章鱼出品V1_Setup_v1.0.0.exe`
2. 按向导选择安装位置（默认用户目录，无需管理员权限）
3. 勾选"创建桌面快捷方式"后完成安装
4. 从开始菜单或桌面图标启动

### 源码方式
```bash
pip install PySide6 numpy scipy soundfile mutagen av
python run.py
```

## 四、无损鉴别分析

### 操作步骤
1. 添加文件后点击 **开始分析**
2. 等待进度条完成，列表中每个文件显示 `[判定 分数]` 并按等级着色
3. 点击文件查看详情：
   - **上半区**：Spek 风格频谱图，红色虚线 = 检测到的高频截止位置
   - **判定行**：大号彩色结论 + 格式/采样率/声道/位深/时长
   - **检测方法表**：4 种算法各自的得分、结论、关键指标
   - **音质维度表**：动态范围/削波/立体声/采样率的 PASS-WARN-FAIL 评级
   - **文本报告区**：完整分析细节（可复制）

### 扩展名警告
若文件扩展名与实际内容不符（如 `.flac` 实为 MP4/AAC），文件名后会标注
**⚠扩展名不符**——这本身就是"假无损"的典型伪装手法。

### 导出报告
点击 **导出报告** 将全部已分析文件的结果保存为 TXT 文本。

## 六、标签编辑页签

### 表格编辑
- 每行一个文件，每列一个标签字段，**双击单元格直接编辑**
- 改动的单元格显示为**橙色**，点击 **保存修改** 统一写回
- **重新读取**：放弃未保存的改动，重新从文件加载

### 批量赋值
1. 表格中选中多行（Ctrl/Shift 多选）
2. 在"批量赋值"区选择字段、输入值（留空 = 清除该字段）
3. 点 **应用到选中行**，再点 **保存修改**

### 文件名 → 标签
文件名规律但标签缺失时使用：
- 模式示例：`%artist% - %title%`、`%tracknumber%. %title%`
- 点 **文件名 → 标签（选中行）** 解析并填入表格，确认后保存

### 标签 → 重命名文件
- 按模式（如 `%tracknumber%. %title%`）批量重命名选中文件
- 自动过滤 Windows 非法字符，重命名前会弹确认框

## 七、判定结果解读

| 等级 | 分数 | 含义 |
|---|---|---|
| 🟢 真无损 | ≥85 | 各项检测均无异常 |
| 🟢 大概率真无损 | 65-84 | 轻微异常，大概率正常 |
| 🟡 轻度嫌疑 | 45-64 | 部分指标异常，建议结合耳听判断 |
| 🟠 大概率假无损 | 25-44 | 明显异常特征 |
| 🔴 假无损 | <25 | 确凿的有损转码/升频伪造证据 |
| ⚫ 有损格式 | 0 | 本身就是 MP3/AAC 等有损容器 |

> 说明：电子乐等天然高频少的流派可能出现误报；分析结果是参考指标而非绝对结论。

## 八、常见问题 FAQ

**Q: 提示"文件损坏、被平台加密或内容并非音频"？**
A: 该文件可能是音乐平台的加密缓存（如网易云/QQ音乐下载），音频区被加密，任何解码器都无法读取。请先用解密工具还原为普通音频文件。

**Q: 提示"⚠扩展名不符"？**
A: 文件扩展名与真实内容不一致（例如把 M4A 改名成 FLAC）。这不影响分析——软件按真实内容解码，但这通常意味着该文件来路可疑。

**Q: 为什么某些真 FLAC 只得了"轻度嫌疑"？**
A: 可能是母带本身高频内容少（老录音、电子乐），或经历过合法的重采样。点开该文件查看各检测方法明细，若只有单一方法扣分且分值接近阈值，大概率为误报。

**Q: 分析速度慢？**
A: 确认已勾选"多进程并行"；单个大文件的分析耗时与文件时长成正比。

**Q: 支持哪些格式？**
A: 分析：WAV/FLAC/AIFF/DSF/MP3/OGG/OPUS/M4A/AAC/WMA/APE（libsndfile + FFmpeg 双解码引擎）；标签编辑：前述格式的 ID3v1/ID3v2.3/Vorbis Comment/MP4 Atom/ASF/APEv2 标签。
